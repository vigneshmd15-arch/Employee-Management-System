# Employee Management System

A full-stack Employee Management System developed using:

- Java
- Spring Boot
- React.js
- MySQL
- REST APIs
- Axios

## Features

- Add Employee
- View Employees
- Update Employee
- Delete Employee
- Search Employees

## Project Structure

- backend - Spring Boot application
- frontend - React application

## How to Run

### Backend
Run EmployeeApplication.java.

### Frontend
cd frontend
npm install
npm run dev
